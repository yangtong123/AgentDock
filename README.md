# AgentDock

AgentDock is a multi-project coding-agent orchestrator for Claude Code, Codex, and future coding-agent providers.

It is designed to coordinate isolated development tasks across multiple repositories with configurable workflows, Git worktrees, deterministic verification, human approval gates, mobile IM control, and GitHub integration.

## Status

AgentDock is in early development. The first implementation milestone is **V0.1 — Core Foundation**.

See [`docs/ROADMAP.md`](docs/ROADMAP.md) for the planned path to V1.0.
